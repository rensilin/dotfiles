# 文件编辑工具

- 创建或修改文本文件时，默认使用专门的文件写入或编辑工具（如 `apply_patch`）。简单的新增、删除、替换和局部改动必须使用这类工具，不得用终端里的 Python、sed、Perl、重定向或 heredoc 代替。
- 只有修改逻辑本身比较复杂，需要程序化解析、计算或转换，难以用直接补丁清楚可靠地表达时，才允许通过终端脚本写入文件。文件多、路径在工作区之外、需要额外写入权限、工具调用更方便，都不构成例外。
- 专门的编辑工具遇到权限或能力限制时，应明确说明限制并寻求受支持的解决方式，不得自行改用终端写入简单修改。
- 确需使用终端脚本写文件时，先说明复杂性和使用理由，完成后展示实际修改的 diff，方便用户审阅。
